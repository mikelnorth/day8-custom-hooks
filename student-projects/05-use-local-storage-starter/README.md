# 05 — useLocalStorage (Day 8 Exercise 3 starter)

Build `useLocalStorage` in `src/hooks/useLocalStorage.js`, then swap it in for `useState` in the
name saver and the notes input. Use the keys `day8-ex3-name` and `day8-ex3-note`.

```bash
npm install
npm run dev
```

Requirements:

- value loads from localStorage
- updates are saved
- refresh keeps data

Check by **refreshing the page**. To start over, open DevTools > Application > Local Storage,
select the key, and delete it.
